# How to Get Your API Keys

## 1. Anthropic Claude API Key

1. Go to: https://console.anthropic.com/
2. Click "Sign Up" (or "Log In" if you have an account)
3. Once logged in, go to "API Keys" in the left sidebar
4. Click "Create Key"
5. Give it a name like "AI Art Discovery"
6. Copy the key (starts with "sk-ant-...")
7. Save it somewhere safe - you'll need it later

IMPORTANT: You get $5 free credit to start!

## 2. OpenAI API Key

1. Go to: https://platform.openai.com/
2. Click "Sign Up" (or "Log In")
3. Go to: https://platform.openai.com/api-keys
4. Click "Create new secret key"
5. Give it a name like "AI Art Discovery"
6. Copy the key (starts with "sk-...")
7. Save it somewhere safe

IMPORTANT: New accounts get $5 free credit for 3 months!

## 3. Google Gemini API Key

1. Go to: https://makersuite.google.com/app/apikey
2. Click "Get API key"
3. Click "Create API key in new project"
4. Copy the key
5. Save it somewhere safe

IMPORTANT: Gemini has a generous free tier!

---

Keep all three keys handy - you'll paste them into a file in a few minutes.
